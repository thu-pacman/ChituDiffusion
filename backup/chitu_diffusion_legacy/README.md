# Legacy ChituDiffusion backup

This directory preserves the pre-EPAC `chitu_diffusion` implementation and its
associated tests, configurations, experiments, service framework, FlexCache,
DiTango, and ChituBench artifacts.

The archive is intentionally excluded from packaging and default test
collection. Its Python sources retain their original imports for historical
reference and are not expected to run beside the replacement
`chitu_diffusion` package.

FlexCache and ChituBench are preserved without adaptation in this migration.
They will be integrated and validated again as separate follow-up work.
