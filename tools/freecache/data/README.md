# FreeCache v2 canonical calibration inputs

These compact numerical inputs reproduce the released 2026-09-09 preview.
They contain no weights, generated images or full velocity tensors. Each
`traces.json` contains 40 complete trajectories (8 prompts × seeds
42/44/45/46/47), represented by 50×50 velocity Gram matrices and 51 actual
sigmas. Their original bytes are retained; `manifest.json` records SHA256 and
original repository-relative source paths. Total input size is about 4 MiB.

Run from the repository root:

```bash
python -m tools.freecache.preprocess reproduce --check-runtime \
  --output outputs/freecache-reproduction/profiles.json
```

This verifies input hashes, recomputes all budget-extension rankings, applies
the nine historical preset overrides, and compares all 150 resulting profiles
with the installed runtime. Use the checkout environment; the tool is not
included in the inference wheel.

| File | Role |
| --- | --- |
| `<family>/traces.json` | Teacher-path Grams and sigma grid, used by CPU fitting |
| `<family>/propagation.csv` | 32 finite-perturbation measurements: 16 positions × 2 prompts, seed 42 |
| `<family>/searched_dense.json` | Historical selected schedules and coherence/weight-source metadata |
| `selected_presets.json` | Exact public F10/F17/F25 overrides, including public IDs |
| `legacy-selected-profiles.json` | Earlier selected profiles; source of Z-Image F10/F25 |
| `legacy-provenance.json` | Original budget compiler input/source hashes and proxy scores |
| `prompts.json` | Text for the eight calibration prompt IDs |
| `manifest.json` | Hashes of the canonical inputs and family mapping |

The legacy provenance describes the old research checkout, not files expected
to exist in a fresh clone. The standalone implementation now lives in
`tools/freecache/preprocess.py`; numerical parity is tested against the released
tables. The nine preset overrides are preserved historical selections, not
regenerated by greedy deletion: Qwen/FLUX and Z-Image F17 match `searched_dense`,
while Z-Image F10/F25 match `legacy-selected-profiles`. Those historical search
and quality-selection decisions are not claimed to be replayed by `reproduce`.

Historical collection used 1024², 50-step model-native FlowMatch Euler,
BF16, model-default guidance (Z-Image 5, Qwen 4, FLUX 3.5). The original Grams
were accumulated in float32 before serialization; the new collector records
float64 CPU Grams and labels that difference. Bitwise regeneration of these
inputs on a different software/backend stack is not promised. The supplied
inputs, rather than a recollection with new dependencies, are authoritative
for CPU reproduction.

The propagation direction is normalized `v[step-2] - v[step]`, injected after
that Euler update. Magnitude is relative to the norm of the pre-update latent
(Z-Image 0.1, Qwen/FLUX 0.01). The fitter deliberately reads `final_deviation`,
not `gain`; weight semantics are an empirical historical response curve.
Coherence is 0 / 1 / 0.98 for Z-Image / Qwen / FLUX. No directional propagation
operator, online state response or perceptual guarantee is encoded here.

These are historical development data, not a new untouched holdout. The final
profiles combined several rounds of experiments; an aggregate from-scratch
one-H20-hour preprocessing cost was not established. CPU recompilation does
not erase that collection/selection cost. See the public
[preprocessing guide](../../../docs/usage/freecache-preprocess.md) for the
separate workflow and validation gates for new candidates.
