# Wan FPP：BF16 基准与已知质量损失

本页比较同为 BF16 的完整序列与 FPP，不比较 FP32/BF16 精度转换。
FPP 是有损近似：滚动 KV、延迟 latent 反馈与末层特征复用均可能改变结果。
目前应作为实验性预览审阅，不能宣称质量保持或已获得稳定加速。

## 历史真实权重实验

数据来自 2026-09-10 的移植提交 `4e6ce813ebc267135f71da31e03d96463fce70dd`，
不是本次基于更新主分支的 PR 重新生成。核心 FPP 调度保持相同，主分支的导出、CLI 和
VAE 接口已更新。机器可读数值见 [quality-summary.json](../assets/fpp/quality-summary.json)。

ModelScope 官方 Wan2.1-T2V-1.3B/14B Diffusers 权重，经文件 SHA256 校验；
480×832、81 帧、50 步、UniPC、shift=3、CFG=7.5。狐狸 seed=42，帆船 seed=73。
同一场景固定初始 FP32 噪声与 BF16 文本嵌入；Transformer BF16（保留原生 FP32
conditioning）、VAE FP32、tiling 开启、并行 VAE 关闭、TF32 关闭。

完整序列基准每 CFG 分支 CP=4；FPP 为 PP=4、CP=1。1.3B 使用四卡本地 CFG，
14B 使用八卡 CFG=2。FPP warmup/cooldown=2/2，refresh_interval=50。
总 token 数 32760，M=4/7/14 分别为 8190/4680/2340 tokens/patch，均无 padding。
模型原生卷积 `patch_size=[1,2,2]` 不变。默认轮转开启，M 同时改变大小和访问顺序。

| BF16 场景 | M=4 PSNR / SSIM | M=7 | M=14 |
| --- | ---: | ---: | ---: |
| 1.3B 狐狸 | 19.12 / .766 | 18.43 / .769 | 17.45 / .731 |
| 1.3B 帆船 | 15.47 / .535 | 14.65 / .487 | 13.81 / .405 |
| 14B 狐狸 | 14.17 / .554 | 12.99 / .437 | 11.84 / .427 |
| 14B 帆船 | 17.66 / .566 | 16.95 / .544 | 16.55 / .564 |

PSNR/SSIM 来自有损编码前的原始帧，仅表示与 BF16 参照的像素相似度，不能替代
审美、提示词遵循或时序质量评价。每模型仅两个提示词、各一个种子，不作总体排名。

抽帧中，1.3B 帆船的湖面/山体出现横向条纹，M=14 尤其明显；14B 完整 BF16
保留竖立的帆，FPP 中帆形状丢失或扁平化。1.3B 基准本身生成机动船而非红帆船，
这一基准已有的提示词问题不计为 FPP 引入的损失。

## 1.3B 帆船、M=14 控制

| 预热 / 收尾 | 完整 / 异步步数 | PSNR | SSIM |
| --- | ---: | ---: | ---: |
| 2 / 2 | 4 / 46 | 13.81 | .405 |
| 10 / 10 | 20 / 30 | 26.93 | .880 |
| 50 / 0 | 50 / 0 | ∞，MSE=0 | 1.000 |

10/10 控制的抽帧中条纹明显减轻；全同步控制的所有原始像素与完整 BF16 数值一致。
这把问题范围缩小到异步路径，但未区分 stale KV、反馈延迟、特征混龄或实现缺陷。
同时增加预热和收尾也无法分别识别二者贡献；此控制尚未在 14B 重复。

## 后续验收

先复核分布式与相同反馈延迟的单进程参考，再拆开测试 KV、反馈、末层特征、
遍历顺序、warmup/cooldown/refresh 的影响。`schedule=step` 与 stream 的布局和轮转
也不同，二者对比只是粗粒度对照，不能自动归因于单一机制。

保持 solver、sigma 网格、CFG、噪声、VAE 与 attention backend 一致，扩大未用于调参的
prompt/seed 集合；同时记录主观评分、语义/时序指标与原始帧相似度。性能需要同机器、
同 GPU 预算、热身后的多次测量，并分开报告去噪时间、VAE、端到端延迟和峰值显存。
本轮没有证明优于优化后的完整 BF16 CP 基准，也未承诺跨模型的最优 patch 配置。
